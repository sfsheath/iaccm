# SOURCES — published typology index

Master index of typology PDFs kept in this folder. Drop a PDF here, add an entry below, and cite it from the relevant category file by author/short-title.

**Efficiency rule:** never open every PDF for an identification. Use the category file to narrow to a candidate type, find that type's source here, and open only that file — eventually only the listed pages.

## Stage of this index

Currently **Stage 1 — filename list per category** (which PDFs are relevant to each category). Migrate incrementally to **Stage 2 — page maps** (type → file → page range) as time allows, starting with the most-used references (Hayes ARS, Ramon T-series, Keay).
